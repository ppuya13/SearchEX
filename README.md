# SearchEX  
<br>

`SearchEX` is a RimWorld mod designed to extend the vanilla world search (`Z`) with regular expressions and more search options.  
It aims to make finding world objects, landmarks, and tiles easier without replacing the familiar search interface.
<br><br>

> **Development Status:** Work in progress. The features below describe the planned functionality and are not yet confirmed as implemented.

### ⚙️ Features
- 🔎 **Regular Expression Search**: Search using regex patterns instead of only plain text.  
- 🌍 **Expanded Search Scope**: Choose between vanilla world-search targets and all world tiles.  
- 🗺️ **Detailed Tile Search**: Optionally search properties shown in the world tile inspection UI, including terrain and climate information.  
- 🧩 **Vanilla UI Integration**: Keep using RimWorld's existing `Z` world-search window, with additional settings.
<br><br>

### 🧩 How to Use
1. Open the world map in RimWorld and press `Z` to open the world search.  
2. Enter a regular expression to search for matching locations.  
3. Use the search settings to change the search scope and enable detailed tile-property matching.  
4. Select a result to jump to its location on the world map.

Installation instructions will be added when a build is available.

`SearchEX`는 RimWorld의 기본 월드 검색(`Z`) 기능에 **정규식 검색과 다양한 검색 옵션**을 추가하기 위한 모드입니다.  
기존 검색창의 사용 방식을 유지하면서 월드 오브젝트, 랜드마크, 타일을 더 편리하게 찾는 것을 목표로 합니다.
<br><br>

> **개발 상태:** 개발 중입니다. 아래 기능은 구현 예정 사항이며, 아직 구현 완료된 기능을 의미하지 않습니다.

### ⚙️ 주요 기능
- **정규식 검색**: 일반 문자열뿐 아니라 정규식 패턴으로 검색  
- **검색 범위 확장**: 기존 월드 검색 대상과 전체 월드 타일 중 선택  
- **타일 상세 정보 검색**: 월드 타일 정보창에 표시되는 지형·기후 등의 속성을 검색 대상으로 추가  
- **기본 UI 유지**: 기존 `Z` 월드 검색창을 활용하고 검색 설정 기능 추가
<br><br>

### 사용법
1. RimWorld 월드 화면에서 `Z`를 눌러 검색창을 엽니다.  
2. 정규식을 입력해 원하는 위치를 검색합니다.  
3. 검색 설정에서 검색 범위와 타일 상세 정보 검색 여부를 변경합니다.  
4. 검색 결과를 선택해 해당 위치로 이동합니다.
